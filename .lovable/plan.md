# 重设计 jms 本机控制台

## 目标
按已选“技术仪表盘”方向重做现有原型，保留配置与操作记录两条核心工作流，统一为石墨橙光、现代工程字体与侧栏工作台。

## 实现范围
- 重构首页为配置工作台：首次引导、JumpServer 连接、Jenkins 实例、项目映射、资产清单与项目编辑状态。
- 新增 `/records` 操作记录页：项目筛选、命令搜索、刷新与导出、可折叠命令结果和状态统计。
- 建立可收起的统一侧栏与顶部状态区，桌面保持高信息密度，窄屏改为可操作的单列布局。
- 保留当前原型的模拟交互；凭据继续脱敏，不接入真实内网或后端。
- 使用语义化设计变量实现石墨、暖橙、成功绿、正式红、测试蓝，并补齐两页独立页面信息。

## 验证
- 检查配置、项目编辑、页面切换、筛选、搜索、折叠和导出反馈。
- 在 1440×900、1280 宽和窄屏下检查溢出、遮挡、可读性与控制尺寸。
- 检查页面运行错误与关键交互结果。

## 技术说明
继续使用当前 TanStack Start 原型实现；这次交付是可交互设计参考，不改接口契约，也不实现真实 JumpServer 连接。
